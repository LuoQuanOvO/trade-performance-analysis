# 黑色系商品研究: 螺纹钢基差与库存分析

> ⚠️ **存档说明**: 本文档为 v1 版本(数据截至2026-08,期货3015/基差-7/库存34417/r=0.59),
> 数字已被仓库主 README 与 `black_series.py` v2 取代(最新数据2026-09-04)。
> 基差口径为 **现货-期货**(行业/教材口径),本文表述与现版一致,但数据为旧快照,仅供参考。

针对大宗商品贸易岗位的实战研究项目。以螺纹钢为例,建立"期货价格+现货基差+库存"的
基本面跟踪框架,展示对黑色系产业链的研究能力。

## 项目目标

大宗商品贸易公司的核心业务之一是期现结合与套期保值。本项目演示:
1. 基差(现货-期货价差)的跟踪与解读
2. 库存周期的识别(累库/去库)
3. 价格与库存的联动关系
4. 基于基差结构的交易/套利逻辑

## 数据来源

- akshare 免费数据接口
- 螺纹钢期货主力连续(新浪):2025-01 ~ 至今,392个交易日
- 螺纹钢现货价与基差(现货升贴水):近120个交易日
- 螺纹钢库存:72条

## 核心结论(2026年8月)

| 指标 | 数值 | 解读 |
|------|------|------|
| 期货主力收盘 | 3015 元/吨 | 价格处于近年低位区间 |
| 最新基差 | -7 元/吨(现货贴水) | 期货小幅升水 |
| 基差率 | -0.23% | 接近平水 |
| 近120日贴水天数占比 | 85% | 期货持续升水结构(contango) |
| 库存 | 34417 | 近30日去库-15993(旺季去库) |
| 价格-库存相关性 | r=0.59 | 中等正相关 |

### 研究解读

1. **基差结构**:当前期货升水(contango)为主导结构,现货贴水。基差从历史低位
   回升说明市场对远期需求预期改善
2. **库存周期**:近30日大幅去库(-15993),处于"去库存"阶段,若去库延续,
   现货走强可能带动基差从贴水转升水,是期现正套的观察窗口
3. **价格-库存联动**:r=0.59 说明库存是价格的领先/同步指标,可用库存变化
   作为价格方向的辅助判断
4. **套利逻辑**:基差率接近0时,期现套利空间有限;若基差扩大至±2%以上,
   关注正向/反向套利机会
