# Trade Performance Analysis

对个人衍生品实盘交易记录(821个完整仓位)进行绩效归因分析的项目,含FXReplay系统化回测复盘。

## 项目背景

独立实盘交易者,以价格行为(Price Action)体系为核心进行市场结构分析。
本项目用 Python(pandas + matplotlib + pyecharts)对 19 个月的真实交易记录进行系统性统计分析,
以数据发现交易问题并驱动策略迭代。

项目主线:先付出真实学费(前期高频乱做、3次仓位强平、亏损集中),再通过数据归因把
"亏在哪里、为什么亏、改进是否生效"逐项量化——阶段亏损收窄87%、盈亏比自0.39修复至0.79、
手续费绝对额下降92%;账户未发生爆仓(资金未归零)。口径定义见下节,改进不是赌出来的,而是归因+验证出来的。

## 口径定义(全文统一)

| 术语 | 定义 | 报告期数据 |
|------|------|-----------|
| 强平 | 单笔仓位被交易所强制平仓(仓位级事件) | 3 次(2025-01 两次、2026-06 一次极小仓位) |
| 爆仓 | 账户资金归零(账户级事件) | 0 次 |
| 回撤 | 逐仓位累计曲线的峰值→谷值跌幅 | 全期 -451.32 单位(其中 2025H1 -409.71);成交明细口径 -370.65 |
| 大亏 | 单笔亏损超过 5 单位 | 32 笔,其中 24 笔集中于 2025 年 1-2 月;单日最大 -86.5 单位 |
| 胜率 / 盈亏比 | 821 个完整仓位口径 | 47.1%(387盈/433亏/1持平);盈亏比 0.53(近一年 0.79) |
| 胜率 / 盈亏比(成交明细口径) | 按平仓成交单边记录计算(report.html / trade_analysis.py 使用) | 胜率 50.4%(1168笔);盈亏比 0.56——与逐仓位口径不同源,不可直接比较 |

- 成交明细 2394 条,完整仓位 821 个,交易标的为跨资产类别的保证金合约(含贵金属类合约)
- **展示名脱敏**:为保护个人交易信息公开性,品种展示名统一映射为中性代号(如 SYM_XX),
  贵金属/能源类合约(如黄金/白银/原油)保留品类真名,映射逻辑见 `anonymize.py`
- **数据与隐私说明**:完整原始导出数据不随仓库公开(避免泄露个人完整交易记录),仅保留聚合统计结果;
  仓库提供脱敏样本 [data_sample.csv](data_sample.csv)(历史仓位表前60条)供数据格式参考,
  所有分析代码均可复现,如需核验完整数据可在面试时现场演示分析流程。

## 核心发现

| 指标 | 数值 |
|------|------|
| 仓位盈亏(完整配对口径) | -427.42 单位 |
| 手续费+持仓费用 | -204.36 单位(占亏损约 48%) |
| 仓位胜率 | 47.1%(387盈 / 433亏 / 1持平) |
| 盈亏比 | 0.53(平均盈利 +1.01 / 平均亏损 -1.89) |
| 持仓时长 | 中位数 0.4 小时(75%仓位不足1小时,超短线) |
| 做多 vs 做空 | 做多 -398 / 做空 -29 |
| 盈亏因子 | 0.57(成交明细口径)/ 0.48(逐仓位口径) |

### 数据揭示的核心问题

1. **盈亏比失衡是亏损主因**:胜率接近五五开(47.1%),但盈利单持有不足(赚小亏大),
   平均盈利仅为平均亏损的 54%
2. **过度交易成本高**:手续费+持仓费用占亏损约 48%,持仓中位数仅 0.4 小时(75%仓位不足1小时)
3. **方向性差异显著**:做空仅亏 -29 单位,做多亏 -398 单位,逆势做多是主要亏损来源

### 深度分析发现(deep_analysis.py)

| 维度 | 发现 |
|------|------|
| 最大回撤 | -451.32 单位(逐仓位累计口径;其中 2025H1 -409.71)/ -370.65 单位(成交明细口径) |
| 最大回撤(月度汇总口径) | -58.75 单位(月频,平滑了日内波动,仅供参考) |
| 连续亏损 | 最长连续亏损 17 笔(成交明细口径)/ 9 笔(逐仓位口径) |
| 单笔期望 | -0.29 单位(成交明细口径)/ -0.52 单位(逐仓位口径) |
| 星期效应 | 周二亏损最多(-159 单位,206笔),周三盈利(+30) |
| 时段效应 | 0时盈利最多(+55),16时(收盘后)亏损最多(-72) |
| 持仓时长 | 中位数 0.4 小时(超短线,75%仓位不足1小时) |
| 盈亏比敏感性 | 盈亏比提升至1.5 → 总盈亏从 -338 改善至 -118(亏损减少65%) |

**关键结论**:盈亏比(盈利单持有)与交易时段选择是可量化的改进方向,
改进模拟显示修复盈亏比可使亏损降低 65%,这是后续迭代的核心目标。

## 滑动窗口分析(rolling_analysis.py)

用滑动时间窗口(近1月/3月/半年/1年)追踪指标演进,区分"历史问题"与"当前状态"。

| 近1个月 | 66 | 50.0% | 0.45 | -12.2 |
| 近3个月 | 186 | 45.7% | 0.76 | -18.6 |
| 近半年 | 419 | 42.2% | 0.75 | -40.3 |
| 近1年 | 478 | 43.3% | **0.79** | -46.1 |

**关键结论**:总亏损的92%集中于2025上半年(高频乱做期),
近一年盈亏比已从0.53修复至0.79,阶段亏损收窄87%——体系改善是真实的、可量化的。

## 成本结构演进(手续费占比)

过度交易(手续费侵蚀利润)是否改善,是验证迭代效果的另一个指标。

| 阶段 | 笔数 | 手续费(单位) | 盈亏(单位) | 手续费/亏损 |
|------|------|------------|-----------|------------|
| 2025上半年 | 317 | -183.7 | -395.6 | 46.4% |
| 2026年 | 468 | -14.0 | -50.5 | 27.8% |
| 近3个月 | 197 | -6.6 | -18.3 | 36.2% |

**结论**:单笔仓位规模大幅压缩(均仓值约596→44单位,缩小约13倍;单笔均手续费 -0.58→-0.03),手续费绝对额下降92%,
手续费占亏损比例从46.4%降至27.8%——过度交易问题得到系统性改善。
该指标纳入日常监控(近3个月略有回升,持续跟踪调整)。

## 进步轨迹分析(progress_analysis.py)

按时间段切分 821 个仓位,验证交易体系的迭代改进(研究闭环的最后一块)。

| 指标 | 2025上半年 | 2026年 | 变化 |
|------|-----------|--------|------|
| 胜率 | 50.5% | 42.7% | 略降 |
| **盈亏比** | **0.39** | **0.74** | **接近翻倍** |
| 持仓时长(中位数) | 0.2 小时 | 0.6 小时 | 盈利单持有改善 |
| 做空占比 | 49.2% | 61.1% | 向数据证明有效的方向调整 |
| 阶段总亏损 | -395.6 单位 | -50.5 单位 | 收窄87% |
| 月均亏损(按有交易月份) | -79.1 单位 | -6.3 单位 | 收窄92% |

**迭代闭环**:2025上半年高频交易、盈亏比0.39、亏损集中 →
数据复盘识别核心问题(盈利单拿不住+逆势做多) →
压缩单笔仓位、延长持仓、转向做空 →
2026年盈亏比翻倍至0.74,月均亏损从-79.1收窄至-6.3。

**结论**:亏损收窄源于可量化的策略调整,而非运气;数据驱动的改进闭环仍在持续。

## FXReplay 系统化回测复盘(fxreplay_analysis.py)

基于 FXReplay 回放工具对价格行为体系进行系统化验证,33 笔完整记录
(每笔含市场背景、形态、信号质量、入场/止损/出场、MFE/MAE、Review)。

| 指标 | 数值 |
|------|------|
| 样本 | 33 笔(持续扩充中) |
| 胜率 | 57.6%(19胜 / 14负) |
| 总盈亏 | +5.06R(正期望) |
| 平均MFE(R) | 1.77 vs 实际兑现 0.153(兑现率8.7%) |

**关键发现**:
1. **形态归因**:双顶(Double Top)+5.96R、楔形(Wedge)+3.13R 为有效形态;L2(-3.02R)、双底(-3.05R)为亏损来源
2. **市场背景**:趋势(18笔)+3.88R、突破模式(5笔)+3.06R 为正;震荡市(10笔)-1.87R 为负
3. **方向归因**:做空 +9.14R vs 做多 -4.07R —— 与实盘 821 仓位结论一致(空优于多)
4. **MFE 兑现率仅 8.7%**:平均理论盈利 1.77R 只兑现 0.15R,与实盘"盈利单拿不住"问题互相印证,
   两份独立数据集指向同一核心缺陷

## 黑色系商品研究(black_series.py / make_black_report.py)

针对大宗商品贸易岗位的实战研究:以螺纹钢为例,建立"期货价格+现货基差+库存+盘面利润"的多维基本面跟踪框架。
**本次数据截至 2026-09-04**(数据源:akshare,可随时重跑更新)。

> **基差口径**:本框架中基差 = 现货价 - 期货主力收盘价(与国内期货从业教材/行业主流口径一致)。
> 基差为正 = 现货升水(期货贴水);基差为负 = 现货贴水(期货升水)。

| 指标 | 数值 | 解读 |
|------|------|------|
| 期货主力收盘 | 3166 元/吨 | 自8月中旬3016反弹至3166(+5%),价格回升 |
| 最新基差 | -15 元/吨 | 由8月中旬的+62(现货升水62/期货贴水62)转为现货贴水(期货升水),基差自高位回落 |
| 基差率 | -0.48% | 处于样本内4%分位(近180个交易日;偏低)——期货升水处于历史高位区间 |
| **基差率历史分位** | **样本内4%分位(近180个交易日)** | 三个月前从14%→64%回升(期货贴水加深),本次重新降至4%(期货转升水),基差结构反复切换 |
| 库存(交易所口径) | 78146 吨 | 近30日累库 +51252 吨(去库转累库,仓单加速累积) |
| 价格-库存相关性 | r=0.29 | 水平值相关,仅作辅助参考;该系数随数据源修订而变动,以最新运行为准 |
| **盘面利润** | +626 元/吨 | 维持偏高水平,钢厂增产动力强 |

**期现正套损益测算(买入现货+卖出期货,资金成本年化4.5%)**:正套盈亏 = 目标基差 − 初始基差 − 资金成本,
盈亏平衡基差 = 初始基差 + 资金成本。当前基差 -15(现货贴水/期货升水):
按保守的"收敛至平水"情景,30天净收益约 **+3元/吨**(资金成本约11.6元/吨),仅薄利;
按"收敛至样本均值"情景(样本期均值,以最新运行为准)测算空间更大,但依赖基差均值回归假设。
S2信号提示基差收敛接近完成——反套离场区/正套观察。

**跟踪信号表**:以"基差分位 + 库存拐点 + 盘面利润"三维触发,
当前 S2(基差修复接近完成/反套离场)、S5增产压力已触发(S1基差修复观察、S3基差修复受阻未触发)。

**研究结论**:8月中旬至9月初框架捕捉到第二次市场状态切换——基差+62→-15(现货升水转现货贴水,即期货贴水转升水)、
分位64%→4%、库存加速累库(+51252吨/30日)但价格反弹(+150),典型"涨价与累库并存"背离结构,
反映资金与情绪推动期货走强,但基本面库存压力未解。**框架的价值在动态跟踪**:结论是动态的,
框架是常驻的——当前期货升水处于历史高位(基差率4%分位),保守情景下正套仅薄利(均值回归情景空间更大但依赖假设),
关注库存拐点与基差回落后的再平衡机会。
交互式报告见 [black_series/black_series_report.html](black_series/black_series_report.html)。

**已知简化与口径说明**(框架为近似口径,非实盘交易模型):
- 基差取即期主力合约、价格图为主力连续合约,换月时两者存在跳变差异,分位/均值为近似;严格期现套利应锚定具体交割月合约
- 库存为交易所库存(仓单)口径,与社会库存(钢厂+贸易商)走势可能背离
- 正套测算仅计资金成本,未计仓储/增值税/交割/物流费用,实际净收益更低
- 价格-库存相关性为水平值相关,两者均为趋势序列,仅作参考;更严谨可用变化量相关
- S1-S5 阈值为经验值(30%/70%/500元/吨),可调,未做历史状态标定

## 相关工具:仓位计算器(position_sizer/)
