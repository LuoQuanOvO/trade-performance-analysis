# BPA 日内量化风控终端与实盘执行工具集 (BPA Risk & Execution Suite)

本项目是一套围绕 **价格行为学 (Brooks Price Action, BPA)** 与 **严格 1R 风险预算管理** 构建的实战风控与辅助执行工具集。

## 核心组件

### 1. BPA 日内量化风控与概率模拟终端 (`BPA交易风控与概率模拟终端.html`)
单文件动态交互式风控终端，原生 Canvas 绘图，支持离线在任意现代浏览器中直接运行：
- **按日蒙特卡洛随机模拟 (Monte Carlo Simulation)**：200 条权益路径推演，区分理想零摩擦与现实磨损均值线，量化双边费率与滑点损耗 (Fee Drag) 对期望值的吞噬；
- **极端连败与破产压力测试 (Stress Test & Risk of Ruin)**：基于胜率、盈亏比与样本笔数推演连续亏损概率分布与理论破产概率曲线；
- **凯利公式 (Kelly Criterion) 理论极限**：动态测算数学最优单笔仓位上限，指导资金管理边界；
- **日内回撤与硬熔断机制**：内置单日亏损熔断规则，可视化平均最大回撤 (Avg MaxDD) 与风控截断效果。

### 2. MT5 价格行为实盘执行插件 (MQL5 Suite)
- **`BPA_Position_Calculator.mq5` / `.ex5` (仓位精确计算器)**：
  - 盘口自动根据信号 K 线止损点数、合约跳动值 (Tick Value)、浮动点差及账户实时净值，精确计算 1R 对应开仓手数；
  - 将“单笔风险严格锁死在 1%~2%”的纪律在挂单端自动化执行，杜绝人为心算失误与过度下注。
- **`BPA_Quick_Entry.ex5` (快速挂单执行工具)**：辅助交易员快速按预设参数完成标准指令录入。
- **`BPA_Close_All.ex5` (一键紧急全平工具)**：应对突发流动性危机或极端黑天鹅的快速硬熔断工具。
