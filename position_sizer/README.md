# 仓位计算器 (Position Sizer)

个人实盘风控工具：按**固定比例风险预算**（Fixed-Fractional Risk）计算每笔仓位，
把手续费、合约最小步进、强平距离全部纳入计算——把"单笔风险 1%-2%"的交易纪律工具化。

## 为什么写这个工具

个人衍生品实盘交易中，最容易失控的就是仓位：仓位大了，一次止损吃掉一个月利润；
仓位小了，风险暴露不足。手算很容易漏掉手续费和合约步进约束。

这个工具解决三个问题：
1. **风险预算纪律化**：输入止损距离，自动算出"亏到止损时正好亏掉计划风险预算"的仓位
2. **成本不隐形**：双边手续费计入总亏损，避免"算着不亏、实际亏损"的错觉
3. **强平风险前置**：检查强平距离与止损距离的关系，避免"止损还没触发就先爆仓"

## 核心公式

```
风险预算   = 总资金 × 风险%
仓位价值   = 风险预算 / (止损% + 双边手续费%)
保证金     = 仓位价值 / 杠杆
强平距离%  ≈ 1/杠杆 - 维持保证金率
```

打止损时：`价格止损 + 手续费 = 风险预算`，实际亏损恰好等于计划亏损。

**强平预警**：若 `强平距离 < 止损距离`，说明止损单还没触发就会先被强平——
此时降低杠杆或收窄止损。

## 功能

| 功能 | 说明 |
|------|------|
| 合约（带杠杆） | 固定 10x，支持按合约步进搜索最大可开单位数 |
| ETF（无杠杆） | 万0.5 费率 + 单边最低 0.1 元佣金建模 |
| 强平距离预警 | 隔离保证金简化估算，止损失效前主动提示 |
| 配置持久化 | 资金/风险参数存 JSON，支持旧配置自动迁移 |

## 使用方法

```bash
python position_sizer.py
```

交互命令：`c` 计算仓位 / `config` 重设参数 / `m` 改资金 / `s` 切换模式 / `q` 退出

示例（合约，10x 杠杆，止损 2%）：

```
合约价值:    1980.00 单位
保证金:      198.00 单位  (19.8%)
强平距离:    9.6%
价格止损:    39.60 单位
手续费:       1.43 单位
总亏损:      41.03 单位  (预算 1.0%)
```

## 说明

- 纯标准库实现，零第三方依赖
- 强平距离为隔离保证金下的简化估算（未计手续费与持仓费用），仅供仓位决策参考
- 本工具用于个人风险管理实践，不构成投资建议
